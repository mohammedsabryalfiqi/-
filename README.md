# مكتبة الخطوط العربية 🖋️

موقع لتصفّح الخطوط العربية ومعاينتها بجملة مخصّصة ورفع خطوطك الخاصة — مبني بنظام **Vite + React + TypeScript + Tailwind CSS** ومتوافق تمامًا مع **Lovable**.

## المزايا

- **20 خطًا عربيًا مفتوح المصدر** مدمجًا في المكتبة (القاهرة، أميري، تجوال، نوتو كوفي…)
- **معاينة حيّة**: اكتب جملة المعاينة وستظهر تحت اسم كل خط بخطّه نفسه
- **رفع خطوط** TTF / OTF / WOFF / WOFF2 من المتصفح — تُحفظ في IndexedDB بدون أي سيرفر
- **قراءة بيانات الخط تلقائيًا** من الملف نفسه (الاسم، المصمم، الرخصة، المحاور المتغيّرة، دعم العربية)
- بحث وتصفية (عربي / متغيّر / ثابت / لاتيني) وترتيب
- صفحة تفاصيل لكل خط: عيّنات الحروف، منزلق الوزن للخطوط المتغيّرة، نسخ كود CSS، تنزيل الملف
- مظهر فاتح/داكن + واجهة RTL كاملة

## التشغيل محليًا

```sh
npm install
npm run dev
```

ثم افتح `http://localhost:8080`

## التشغيل على Lovable

المشروع بهيكل Lovable القياسي (Vite + React + TS + Tailwind + lovable-tagger) — يكفي ربط المستودع من GitHub داخل Lovable وسيعمل مباشرة.

> ملاحظة: الخطوط التي يرفعها الزائر تُحفظ في متصفحه فقط (IndexedDB). إذا أردت مكتبة مشتركة بين جميع الزوار، يمكن ربط المشروع بـ Supabase من داخل Lovable لاحقًا.

## البنية

```
├── index.html              # نقطة الدخول (RTL عربي)
├── public/fonts/           # ملفات الخطوط المدمجة (20 خطًا)
├── src/
│   ├── App.tsx             # الصفحة الرئيسية
│   ├── components/         # بطاقة الخط · نافذة الرفع · نافذة التفاصيل
│   ├── lib/
│   │   ├── fontParser.ts   # قراءة جداول sfnt (name/cmap/fvar) في المتصفح
│   │   ├── fontLoader.ts   # تسجيل الخطوط عبر FontFace API
│   │   └── db.ts           # تخزين الخطوط المرفوعة في IndexedDB
│   └── data/fonts.json     # بيانات الخطوط المدمجة
└── tailwind.config.ts
```

## الرخص

جميع الخطوط المدمجة مفتوحة المصدر برخص SIL OFL أو Apache. الخطوط المرفوعة تبقى ملك أصحابها.
